# Linux AJ Terminal OS Portfolio

A hacker-themed Linux AJ Terminal OS portfolio website for Aaqib Jeelani, Full Stack Developer & IT Manager.

## Features

- 🖥️ Linux AJ Terminal OS desktop interface with hacker aesthetic
- 🚀 Boot screen animation with Linux-style kernel messages
- 🔐 Login screen with system information display
- 📱 Fully responsive design (desktop and mobile)
- 🎵 Startup sound using Web Audio API
- 🪩 Draggable, resizable, and minimizable windows
- 📊 Interactive taskbar with window management
- 🎯 Start menu with OS applications
- 📋 Complete portfolio content (About, Skills, Projects, Experience, Contact, Resume)
- 💻 Functional terminal with custom commands
- 📄 PDF resume preview and LinkedIn integration
- 📜 Custom right-click context menus
- 🌍 Multiple desktop applications (Terminal, File Manager, Text Editor, etc.)
- 🟢 Green hacker-theme color scheme

## Technologies Used

- Pure HTML5 for semantic structure
- CSS3 with custom XP-style theming
- Vanilla JavaScript for interactivity
- Web Audio API for startup sounds
- Responsive design with CSS Grid and Flexbox
- CSS animations and transitions
